ShadowCue is a free English shadowing practice app for iOS.

## Getting Started

Open the app, choose a course from the course library, then use the practice
screen to watch the lesson video, follow the bilingual cards, replay sentences,
mark vocabulary, and review difficult clips.

## Common Issues

### A lesson video does not play

The first App Store release is intended to use bundled lesson content. If a
course shows that its media is unavailable, update to the latest app version or
report the affected course name.

### Progress looks wrong

Progress is stored locally on the device. Reinstalling the app may remove local
learning progress.

### I need help

Open an issue here:

<https://github.com/jiaqianjing/shadowcue-pages/issues>

Please include the app version, iOS version, device model, and a short
description of what happened.
